# Approved Asset Manifest

| File | Role | Approved use | Prohibited use |
|---|---|---|---|
| `assets/brand/nobull-logo-full-color.svg` | Primary NoBull logo | Light/Eggshell backgrounds, header, light sections | Recoloring, redrawing, distortion, rearrangement, dark backgrounds without contrast |
| `assets/brand/nobull-logo-reverse.svg` | Reverse NoBull logo | Crimson, charcoal, or approved dark backgrounds; footer | Recoloring, use on low-contrast light backgrounds |
| `assets/brand/nobull-icon-crimson.svg` | Standalone NoBull icon | Small accents on light surfaces where a standalone icon is appropriate | Replacing the full logo in the header, generating a 3D gold bull |
| `assets/brand/nobull-icon-reverse.svg` | Reverse standalone icon | Small accents on dark/Crimson surfaces | Recoloring or using as a new logo lockup |
| `assets/book/law-firm-revenue-engine-cover-exact.png` | Exact book cover | Exact front face of book mockups and book-related content | Retyping, regenerating, recoloring, cropping, changing title/subtitle/author, using torn-money motif outside cover |
| `assets/references/homepage-direction-reference.png` | Directional homepage mockup | Composition, section order, brand-bridge intent | Treating placeholder metrics, client logos, ratings, testimonials, or trademark symbols as factual |
| `assets/guidelines/no-bull-brand-guidelines.pdf` | Original brand guidance | Logo, typography, colors, spacing, and brand-device reference | Publishing directly as site content |

## Typography

- Primary: Crimson Pro
- Secondary: Sweet Sans Pro
- Fallbacks: Baskerville and Arial

Sweet Sans Pro may only be used when licensed WOFF/WOFF2 files exist in the project. Do not download an unofficial copy or label a lookalike as Sweet Sans Pro.
