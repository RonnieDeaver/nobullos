## Concurrency ramp note

`front_recovery_ingest_concurrency` defaults to **1** even after the
tuning switch flips. The intended operator ramp is 1 → 2 → 3, with a
60-minute observation gap between ramps and a check that
Front API 429 rate has not increased. Each ramp is a separate row
in this file's table — copy the Post-flip block per ramp step.
